Dip-Catcher: a tiny long-only mean-reversion bot for hourly Solana prices. It buys a symbol only when its price has stretched 2% below its own 18-hour mean, then banks the bounce — take profit at +5%, a 2% trailing stop, a 5% hard stop, or a 24-bar stale exit — and otherwise sits in cash. On the kit's dev window it scores +$158.35 net PnL (+1.58%, max drawdown 3.41%, 52 trades) against buy-and-hold's −$869.34.

## Run it

```sh
node main.ts
```
